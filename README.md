# La Kurumba Unawatuna

Responsive restaurant website concept with an editorial layout, sunset couple line art, overlapping food photography, scroll animations, and a Facebook video embed.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000. No build or dependencies are required.

## Deploy

Upload this directory to any static web host. The entry point is `index.html`.

## Files

- `index.html`: page content
- `style.css`: base styles
- `premium.css`: editorial layout and responsive styles
- `app.js`: navigation, menu tabs, gallery and scroll effects
- `assets/`: local imagery

## Media notes

The sunset couple illustration is AI-generated. Food and interior photographs are illustrative stock imagery, not verified restaurant photos. The Facebook video remains hosted by Facebook; muted autoplay depends on browser and Facebook restrictions. Public listing details should be confirmed with the restaurant before official use.
